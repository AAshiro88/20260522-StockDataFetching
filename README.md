# 即時報價監控系統

透過台灣證券交易所 TWSE MIS 即時行情 API，抓取個股、ETF 及大盤指數的即時報價，並以 Tkinter GUI 顯示於深色主題視窗。同時自動將即時行情寫入 CSV，以及將每日歷史資料寫入本地 Excel 檔案。

## 功能

- **即時報價顯示**：每 10 秒從 TWSE MIS 抓取最新報價，Tkinter 視窗每 0.5 秒刷新
- **指數、ETF、個股分區顯示**：依產業別排序個股，支持自訂高亮標的
- **突發變動警示**：tick 漲跌幅 ≥ 1% 時整行標記（上漲橘底 / 下跌紫底）
- **歷史資料寫入**：每 10 分鐘將各標的的 OHLC 資料寫入 Excel，每日一列
- **即時報價 CSV 匯出**：每 1 分鐘覆蓋寫入 `即時報價.csv`，包含五檔委買委賣

## 檔案結構

| 檔案 | 說明 |
|------|------|
| `main.py` | 程式主體 |
| `start.vbs` | 靜默啟動腳本（無視窗執行） |
| `個股股價.xlsx` | 歷史資料 Excel（程式自動建立/更新） |
| `個股股價 - template.xlsx` | Excel 範本（供參考） |
| `即時報價.csv` | 即時報價匯出（程式自動覆蓋寫入） |

## 環境需求

- Windows 10 以上
- Python 3.12（Anaconda 或 Miniconda）

### 所需套件

```
requests
openpyxl
tkinter（Python 內建）
```

## 啟動方式

### 靜默啟動（無視窗）

雙擊 `start.vbs`，程式以 `pythonw.exe` 後台執行，不會出現命令提示字元視窗。

### 直接執行

```bash
python main.py
```

## 設定說明

個股、ETF、高亮清單均從 `個股股價.xlsx` 的 **main** 工作表讀取：

| 欄位 | 說明 |
|------|------|
| A 欄 | 追蹤個股代碼（每列一檔） |
| B 欄 | 追蹤 ETF 代碼（每列一檔） |
| C 欄 | 高亮代碼（名稱顯示為藍色） |

程式會自動從 `本國上市證券國際證券辨識號碼一覽表` 工作表讀取產業別對照資料，用於個股分類排序。

## 注意事項

- TWSE MIS API 僅在交易時段（週一至週五 09:00-13:30）回傳即時資料
- Excel 檔案若被其他程式開啟，歷史寫入會失敗，視窗上方會顯示錯誤訊息
- `start.vbs` 無視窗執行，如需除錯請直接執行 `python main.py`
